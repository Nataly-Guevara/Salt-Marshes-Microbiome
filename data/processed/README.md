# Processed Chapter 1 data

This directory is reserved for **validated, publication-aligned** lightweight processed data shared across multiple analysis groups (for example, curated feature tables, taxonomic annotations and analysis-ready objects when licensing and size allow).

**Scaffold only.** No new processed data have been imported as part of this refresh. Existing files elsewhere in the repository have not yet been validated against the final manuscript. Raw FASTQ files belong in NCBI SRA under BioProject [PRJNA1446205](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1446205), not in this directory.

Do not upload raw sequencing reads, huge R workspace images, private local paths, credentials or superseded results.
