# Shared H1 / H2 / H3 Chapter 1 workflows

These source scripts contain several analysis types in single R files, following the historical Chapter 1 script organisation. They are kept together rather than splitting code without testing its dependencies.

- **H1:** Natural, BESE, BARE and Degraded **bulk-soil** comparisons.
- **H2:** Natural, BESE and BARE **rhizosphere** comparisons.
- **H3:** paired bulk-soil vs rhizosphere comparisons within Natural, BESE and BARE.

The scripts may include alpha diversity, beta diversity, reference similarity, ANCOM-BC2 differential abundance, sensitivity analyses, taxonomic summaries and related plots. Scripts for specific methods also appear in adjacent `analyses/` folders.

**Publication status: candidate source code under review.** These are privacy-cleaned scripts imported from a local Chapter 1 review bundle. They have not been rerun from this repository. Required inputs and outputs (including the 243 relabelled file references) are not yet populated, and full executable reproducibility is pending. Results should be interpreted using the final manuscript and independently checked outputs.

See `SOURCE_MANIFEST.csv` for original relative paths, the new repository destinations and SHA-256 checksums. No absolute personal directories are in the published manifest.
