# H1, H2 and H3 shared workflows

R scripts covering several analyses in one source file (including diversity, community composition, ANCOM-BC2, reference-similarity tests and plotting). They are retained together to preserve dependencies. `SOURCE_MANIFEST.csv` records original source filenames and checksums.

- **H1:** Bulk soil: Natural, BESE, BARE, Degraded.
- **H2:** Rhizosphere: Natural, BESE, BARE.
- **H3:** Paired bulk soil and rhizosphere in Natural, BESE, BARE.

The matching inputs and outputs are being transferred; end-to-end reruns remain to be verified.
