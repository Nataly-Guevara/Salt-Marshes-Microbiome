# Differential abundance — ANCOM-BC2

**ANCOM-BC2** is the differential-abundance method used in the manuscript. Genus- and ASV-level 16S and ITS analyses are organised by H1 (bulk soil), H2 (rhizosphere), and H3 (paired soil habitats). Source code currently appears in [`../shared_workflows/scripts/`](../shared_workflows/scripts/). Outputs from the local `AMBCOM` directory are being synced. DESeq2 is not used in the final analyses.
